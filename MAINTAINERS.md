# Maintainers

- Repository custodian and administrator: [`ghbvf`](https://github.com/ghbvf)
- Maintainer team: `github:shengming0817/rss-maintainers`

The `rss-incubator` maintainers own this repository's source, workspace, root lockfile, product build
and CI, candidate consumption, upgrades, rollback, and product security response. RSS maintainers are
upstream artifact owners only: they own the RSS Release Surface, API and SemVer, package metadata and
artifact correctness, and fix, yank, and release approval.

Repository access, team membership, maintainer status, and crates.io ownership remain separate
explicit grants.
