# Security

Do not report vulnerabilities in a public issue. Email
[`shengming.jiang@outlook.com`](mailto:shengming.jiang@outlook.com) with the affected revision,
impact, reproduction details, and any known mitigations. The `rss-incubator` maintainers own private
triage, product-impact assessment, temporary mitigation, dependency upgrade or rollback, and
coordinated disclosure for this repository.

If the root cause is in an RSS artifact, the incubator maintainers will coordinate with the RSS
artifact owner while retaining responsibility for the product response. Candidate artifacts receive
no public support, RC, maturity, or release commitment.

This repository currently contains incubation work and a non-publishable smoke package. Support for
any future product must be declared by that product's accepted scope and release policy; presence in
this repository alone does not make a component production-supported.
